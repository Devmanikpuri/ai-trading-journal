# AI Trading Journal

A lightweight, responsive trading journal MVP for recording trades, tracking P&L and reviewing trading behavior.

## Features
- Trade logging: date, symbol, direction, setup, entry, exit, quantity, risk, emotion and notes
- Automatic P&L, win-rate and average-R calculations
- Trade history with delete controls
- Journal analysis that surfaces risk, win-rate and emotional patterns
- JSON export
- Local-first storage using browser localStorage
- Responsive mobile-friendly UI

## Run
This MVP is a static web app. Open `index.html` in a browser, or deploy the repository with GitHub Pages.

## Important
The current coach is a deterministic journal-analysis engine, not a connected LLM. It is designed as the first working MVP. Financial insights are educational and are not financial advice.
